# ObenVoice add-on downloads

Only the latest published version of each add-on is listed here.

## British Emma & George Voices

Adds the British `bf_emma` and `bm_george` Kokoro voices.

- **Version:** `v1.0.0-beta.1`
- **Download:** [ObenVoice British Voices ZIP](https://github.com/LM-Mods/ObenVoice/releases/download/v1.0.0-beta.1/ObenVoice-v1.0.0-beta.1-British-Voices.zip)

Extract the ZIP into the main Obenseuer folder after installing ObenVoice Core.
