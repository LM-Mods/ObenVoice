# ObenVoice add-on downloads

Only the latest published version of each add-on is listed here.

## British Voices

Adds the British `bf_emma` and `bm_george` Kokoro voices.

- **Version:** `v1.0.1`
- **Download:** [ObenVoice British Voices ZIP](https://github.com/LM-Mods/ObenVoice/releases/download/british-voices-v1.0.1/ObenVoice-British-Voices-v1.0.1.zip)

Extract the ZIP into the main Obenseuer folder after installing ObenVoice Core.

## Stalburg Voices Vol. 1

Adds 20 Kokoro-compatible voices and the SV1 Expanded and Pack Only casting
configurations.

- **Version:** `v1.0.1`
- **Download:** [Stalburg Voices Vol. 1 ZIP](https://github.com/LM-Mods/ObenVoice/releases/download/stalburg-voices-v1.0.1/ObenVoice-Stalburg-Voices-v1.0.1.zip)

Extract the ZIP into the main Obenseuer folder after installing ObenVoice Core.
