# Licensing status and recommendation

The original ObenVoice/Obenseuer Dialogue TTS code and documentation are
released under MIT. The approved public copyright identity is
**LM-Mods**. A stable public pseudonym can identify the copyright claimant when
the person or organisation using it actually owns or controls the relevant
rights. The owner approved that identity and the root `LICENSE` wording on
8 November 2026.

OpenAI Codex generated the implementation under human-led design, direction,
selection, testing and release decisions. The repository does not claim that
every machine-generated fragment is independently copyrightable or exclusive.
MIT grants permission over whatever rights LM-Mods is authorised to grant in
the original project material.

Release arrangement:

1. Use the approved MIT licence for original project code and documentation.
2. Keep third-party libraries, models and voices under their original licences.
3. Ship the applicable licence and notice files inside each release asset.
4. Do not describe the complete runtime or optional packages as MIT-licensed.

The adapted `data/characters.json` database is separately available under CC
BY-SA 4.0; see [its attribution and modification notice](../data/LICENSE.md).
That data licence does not apply to the program code.

The source headers and preserved provenance records identify the Python backend
as an independent implementation for Obenseuer. No Universal TTS Mod source
was found in the curated repository. This is evidence from the reviewed files,
not a guarantee about material that was unavailable to the audit.

Outstanding redistribution checks are tracked in
[RELEASE-PACKAGING.md](RELEASE-PACKAGING.md). Pocket remains blocked. The
British voice files have verified pinned provenance.

This document records release preparation and is not legal advice.
