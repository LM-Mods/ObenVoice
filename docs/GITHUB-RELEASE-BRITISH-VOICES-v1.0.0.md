# ObenVoice British Emma & George Voices v1.0.0

Optional Kokoro voice pack for ObenVoice Core.

## Included voices

- Emma (`bf_emma`)
- George (`bm_george`)

## Installation

Install ObenVoice Core first. Extract the ZIP into the main Obenseuer folder
containing `Obenseuer.exe` and allow Windows to merge the `ObenseuerTTS`
folder.

The voice weights are unmodified files from Kokoro-82M revision
`f3ff3571791e39611d31c381e3a41a3af07b4987` and retain their Apache-2.0
attribution. The archive SHA-256 is:

```text
84FB6C0E49E9566433C7D56E227213E7A7ACEE1FA1A3C5E685669F20260A5248
```
