# Minimal Kokoro voice-pack example

Install a completed pack at `ObenseuerTTS\voice-packs\kokoro\example-pack`.

The folder name must match the manifest ID. Each voice ID must be unique, gender must be `female` or `male`, and each file must be a `.pt` file inside the pack folder.

This template intentionally contains no voice weights. Pack authors are responsible for permission, licensing, attribution and safe distribution of every added file.
