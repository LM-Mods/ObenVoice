# Contributing to ObenVoice

Bug reports, fixes, documentation improvements, forks and independently
developed add-ons are welcome.

Before submitting a change:

1. Describe the problem and the affected BepInEx version.
2. Keep changes focused and preserve existing configuration compatibility.
3. Run the relevant tests and avoid committing generated runtimes, models,
   game files, logs, caches, credentials or personal paths.
4. Identify the source and licence of any third-party material.
5. Do not submit code or assets copied from another mod without permission.

By submitting original material, you agree that it may be distributed under
the project's MIT licence. Material under a different compatible licence must
be clearly identified and must not be represented as project-owned work.

Engine add-ons and voice packs can be developed independently using the public
interfaces and examples. Their authors remain responsible for their own
licensing, safety and redistribution compliance.
