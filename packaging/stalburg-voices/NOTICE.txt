  hexgrad/Kokoro-82M (voice tensor styles)
  https://huggingface.co/hexgrad/Kokoro-82M
  Upstream repository declares Apache License 2.0.

Modifications:
  20 new Kokoro-compatible .pt style tensor files were computed from the
  upstream voice tensor files using original procedural PCA/orthogonal style
  steering code. They are derivative modifications, not independently trained
  speakers. These new derivative files differ from their upstream source anchors.
  The original input voice tensors are NOT included unchanged in this ZIP.
  See PROVENANCE.json for each input/source SHA-256 and each output SHA-256.
  Generator source: GENERATOR.py.
