# ObenVoice British Emma and George voices

This optional Kokoro voice pack installs at:

```text
ObenVoice/VoicePacks/Brit/
```

Copy the loose add-on folder contents into the Obenseuer game folder, then
restart the game. It requires an existing ObenVoice Core installation. It does
not include Core, Python, models, settings or logs. Its two casting
configurations install separately under `ObenVoice/Characters`.

Emma and George are unmodified third-party Kokoro-82M voice weights from the
pinned revision recorded in `ATTRIBUTION.txt`. Apache License 2.0 is included.
Version 1.0.1 uses the consolidated `ObenVoice` installation layout and adds
the complete **Brit - Expanded** and **Brit - Pack Only** 292-character
casting configurations. The established pack and voice IDs are unchanged.

Emma and George share their standard Kokoro voice IDs with any other installed
copy of those stock voices. Core resolves duplicate IDs deterministically, but
users should avoid installing duplicate copies when possible.
